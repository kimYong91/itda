### 운동을 어떻게 할지 모르는 사람들을 위한 맞춤 운동 보조 어플 "잇다"
* 기획 및 개발 기간 : 2024.06.11 ~ 07.05
* 배포주소 : http://itda-app-apk-bucket.s3-website.ap-northeast-2.amazonaws.com/

## 개발 동기
1. 취향에 맞는 운동 정보
2. 식단 관리 및 음식 칼로리 정보
3. chatGPT 활용

## 구현 목표
1. 사용자의 건강 정보를 기반으로 맟춤 운동 및 식단 스케줄 생성
2. 사용자의 실제 음식을 기록하고 칼로리를 계산
